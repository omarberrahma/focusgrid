# FocusGrid

A local-first, mobile-friendly habit and focus tracker. FocusGrid starts simple: habits, daily completion, streaks, and a GitHub-style activity grid. Focus sessions, analytics, sharing, PWA support, and cloud sync follow the roadmap.

## Development
```bash
npm install
npm run dev
```

## MVP
- Dashboard and daily habit checklist
- Create and delete habits
- Local persistence
- Activity grid and streak
- Responsive, dark-first UI

## Roadmap
1. Application scaffold
2. Habit engine and activity grid
3. Focus timer
4. Statistics
5. Shareable progress cards
6. PWA
7. Cloud sync (later)

Built with React, TypeScript, Vite, and Lucide.
